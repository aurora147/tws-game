# 韩娱嫂子模拟器 · TWS成员定向版

一款基于虚构设定的交互式文字冒险游戏。在虚拟的韩娱世界中，与TWS成员之一展开爱情故事。

## ✨ 游戏特色

- **6位可攻略成员** - 申惟、金道勋、崔英宰、韩振、韩志薰、李炅潣
- **动态属性系统** - 每个选择都会影响好感度、人气值、心情值、金钱等8个维度
- **多分支结局** - 根据你的选择触发5+种不同的结局（HE/OE/BE/SE）
- **URL分享存档** - 将游戏进度编码为URL，分享给朋友让他们继续你的故事
- **真实韩娱氛围** - 舆论压力、公司干预、粉圈风险等现实设定

## 🚀 快速开始

### 1. 安装依赖

首先确保已安装 [Node.js](https://nodejs.org/) (v16+)

```bash
cd D:/tws-game
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

浏览器会自动打开 `http://localhost:5173`

### 3. 构建生产版本

```bash
npm run build
```

生成的文件在 `dist/` 目录下

## 📖 游戏流程

1. **游戏启动** - 查看游戏简介
2. **角色创建** - 选择身份、目标成员、剧情节奏
3. **故事推进** - 每周推进故事，根据事件做出选择
4. **属性影响** - 每个选择影响不同的属性，决定故事走向
5. **结局触发** - 第12周、24周或36周时根据属性自动触发相应结局

## 💾 存档系统

### URL分享
- 游戏进度自动编码为URL参数
- 复制链接分享给朋友，他们可以直接恢复你的游戏进度
- 示例: `http://localhost:5173/?save=N4IgZglg9gLg7gpgJyQK...`

### JSON导出/导入
- 在游戏中可导出当前进度为JSON文件
- 也可导入之前保存的JSON文件继续游戏

## 🎮 游戏属性说明

| 属性 | 范围 | 说明 |
|------|------|------|
| 好感度 | 0-100 | 男主对你的好感程度，决定关系阶段 |
| 人气值 | 0-100 | 你在粉圈/舆论中的曝光度，人气过高风险增加 |
| 心情值 | 0-100 | 你的心理状态，过低会触发情绪危机事件 |
| 金钱 | ≥0 | 你的经济状况，影响生存压力 |
| 恋情保密度 | 0-100 | 你们关系的隐秘程度，过低会曝光 |
| 公司警觉度 | 0-100 | 男主所在公司对你的警惕程度 |
| 事业压力 | 0-100 | 男主的工作压力，影响相处频率和他的情绪 |

## 🛠️ 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **状态管理**: Zustand
- **样式**: Tailwind CSS
- **存档编码**: LZ-String + Base64
